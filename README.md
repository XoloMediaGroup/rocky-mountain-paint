# Rocky Mountain Paint LLC

A tighter redesign of [rockymountainpaint.com](https://rockymountainpaint.com/). All photos and the logo are from the live site — nothing generated.

## Run

```bash
cd rocky-mountain-paint
npm install
npm run dev
```

## What’s different

- Cleaner type, spacing, and a sticky header that uses his logo
- His job photos as a real gallery (Work), not a cramped Elementor grid
- Same services, reviews, hours, phone, email, Facebook, and Instagram
- “Laquer” labeled as Lacquer (the finish, not a new service)

## Photos

Everything in `public/images/` was downloaded from the current WordPress uploads. Swap files there if he adds new jobs.
